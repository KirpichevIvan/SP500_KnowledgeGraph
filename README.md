# S&P 500 Knowledge Graph: Hybrid Construction & Enrichment Pipeline

Этот репозиторий содержит реализацию научно-исследовательской работы по теме: **«Исследование алгоритмов на основе БЯМ для построения графов знаний и методы синтеза неявных связей для формирования бенчмарка»**.

Проект представляет собой программный конвейер (pipeline) для автоматического создания, наполнения и семантического обогащения графа знаний компаний S&P 500.

📄 **Препринт статьи доступен по ссылке:** [Google Drive](https://drive.google.com/drive/folders/1faq_7FcamfWOq0yu2xfbqPv1Oq-TsMSp?hl=ru)

---

## Цель проекта
Решение проблемы структурной разреженности графов знаний, создаваемых стандартными RAG-системами.
Разработанный гибридный подход комбинирует **Векторный поиск (Vector Search)** и **Большие языковые модели (LLM)** для выявления **неявных связей** (латентная конкуренция, цепочки поставок), которые отсутствуют в явном виде в текстовых источниках.

## Структура репозитория

### 1. Сбор данных
*   **`collect_data.py`** — Скрипт первичного сбора данных. Парсит список компаний S&P 500 с **Wikipedia** и обогащает их финансовыми показателями, описанием и списком топ-менеджмента через **Yahoo Finance API**.
*   **`data/`** — Папка с исходными и промежуточными данными:
    *   `sp500_graph_ready.xlsx` — Результат работы `collect_data.py`, "сырая" база для построения графа.
    *   `classified_reuters_news_mapped.csv` — Датасет финансовых новостей для событийного обогащения.

### 2. Пайплайн построения графа (`build_graph_with_relation_news_info/`)
В этой директории находятся основные скрипты, реализующие логику исследования. Запускаются последовательно:

1.  **`reset_database.py`** — Утилита для полной очистки базы данных Neo4j (удаление узлов, связей и индексов) перед чистым запуском.
2.  **`build_graph.py` (Script 2)** — Создает скелет графа на основе данных из Excel (узлы компаний, секторов, персон) и формирует **явные связи** (Explicit) на основе текстового анализа описаний (Wiki/GDELT).
3.  **`enrich_graph.py` (Script 3)** — Модуль выявления **неявной конкуренции**. Векторизует списки продуктов компаний и находит пересечения в семантическом пространстве.
4.  **`find_supply_chain.py` (Script 4)** — Модуль реконструкции **цепочек поставок** (Supply Chain). Использует LLM для генерации потребностей компаний и векторный поиск для нахождения поставщиков среди других компаний S&P 500. Создает узлы `Resource`.
5.  **`process_news_vectors.py` (Script 5)** — Модуль обработки новостного потока. Использует гибридный поиск (Entity Linking через векторы + валидация LLM) для привязки новостей к графу и создания событийных ребер.

### 3. Аналитика
*   **`check_stats.py`** — Скрипт для подсчета итоговой статистики графа. Анализирует источники данных (`Wiki`, `Vector`, `SupplyChain`, `News`) и вычисляет метрики прироста информативности.

## Установка и запуск

### Предварительные требования
*   Python 3.8+
*   Neo4j Database (локально или в Docker)
*   API Key для LLM (в данном проекте использовался провайдер Polza/OpenAI)

### 1. Настройка окружения
Создайте файл `.env` в корне проекта

NEO4J_URI=bolt://localhost:7687

NEO4J_USERNAME=neo4j

NEO4J_PASSWORD=your_password

POLZA_API_KEY=your_api_key


### 2. Запуск пайплайна
Рекомендуемый порядок выполнения для воспроизведения результатов НИР:
#### 1. Сбор данных (если файла xlsx еще нет)
python collect_data.py

#### 2. Очистка базы (Удаляет все данные в Neo4j)
python build_graph_with_relation_news_info/reset_database.py

#### 3. Построение базового слоя (Wiki + Structure)
python build_graph_with_relation_news_info/build_graph.py

#### 4. Векторный поиск конкурентов
python build_graph_with_relation_news_info/enrich_graph.py

#### 5. Реконструкция Supply Chain (Ресурсы и Партнеры)
python build_graph_with_relation_news_info/find_supply_chain.py

#### 6. Обработка новостей (Событийный слой)
python build_graph_with_relation_news_info/process_news_vectors.py

### 3. Проверка результатов
python build_graph_with_relation_news_info/check_stats.py
